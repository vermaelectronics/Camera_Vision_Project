# M-ESPRIT 2-Antenna DOA Estimator IP

RTL implementation of the **modified ESPRIT (M-ESPRIT)** from

> J. Li, G. Yang, X. Ren, Z. Fu, S. Qiu, "Modified ESPRIT and Unitary-Transformation Form for
> Computationally Efficient DOA Estimation on FPGA", *IEEE Trans. Instrum. Meas.*, vol. 74, 2025,
> Art. 2003209, Section III-A, with the **Cᵖ** improvement of Remark D.

The IP is specialised for a **two-element CRPA baseline** (M = 2) and packaged as a Vivado IP with an
AXI4-Stream data path and AXI4-Lite control. It is a drop-in sibling of `../i_uesprit_2ant`: same
interfaces and register layout, plus a unit-circle "source present" test. All module names carry the
`mesprit_` prefix, so both IPs can be used in one project.

## Algorithm and the M = 2 closed form

| Paper step | Equation | RTL module | M = 2 realisation |
|---|---|---|---|
| Cumulant matrix, no source number needed | (7) | `mesprit_cmc_2x2` | Streaming moments `E[x_m x_n*]`, `E[x_m x0]`, `E[\|x0\|² x_m x_n*]`, combined once per window |
| `Cᵖ` | (38), Remark D | `mesprit_rma_2x2` | Repeated squaring of a 2×2 Hermitian, block-floating-point renormalised (p = 1, 2, 4, 8) |
| `C1 = J1 C`, `C2 = J2 C` | (11), (12) | " | `C1 = [a, b]`, `C2 = [b*, d]` with `C = [[a, b],[b*, d]]` |
| `P = (C1ᴴC1 + μI)⁻¹C1ᴴ`, `Ψ = P C2` | (17), (19) | " | `Ψ = C1ᴴC2 / (\|C1\|² + μ)` is rank one, so its only non-zero eigenvalue is its trace: **ψ = (a + d)·b\* / (a² + \|b\|² + μ)** |
| EVD of Ψ | (20) | — | Not needed (closed form above) |
| `θ = asin(−λ/(2πd)·arg ψ)` | (21) | `mesprit_pie_dar` | `arg ψ = atan2(Im, Re)` (CORDIC; the denominator is real and positive, so no division), `θ = asin(−k·φ)` (block-RAM LUT) |
| Unit-circle test | Remark A | `mesprit_pie_dar` | `\|ψ\|` from the CORDIC magnitude and one division; `off_circle = \|\|ψ\| − 1\| > UC_TOL` |

For an ideal single source, ψ = e^{jφ} exactly. `model/m_esprit_model.py selftest` checks that the
closed form equals the paper's generic M-ESPRIT with a full complex EVD (max phase difference
2e-9 rad).

### Differences from I-UESPRIT (the companion IP)

| | M-ESPRIT (this IP) | I-UESPRIT |
|---|---|---|
| Eigenvalue | Complex, ψ = e^{jφ} | Real, ψ = tan(φ/2) |
| Phase recovery | `arg ψ`, full ±π range | `2·atan ψ`, sensitive near ±π |
| Source-present test | Yes: \|ψ\| ≈ 1 (Remark A) | No real-valued equivalent |
| Larger arrays | Most accurate in the paper and in my simulations | Weak near broadside and for close sources |
| Hardware (M = 2) | 49 DSP, ~11.2 k LUT | 45 DSP, ~10.7 k LUT |
| Accuracy (M = 2) | Same | Same |

## Interfaces

* **Clock/reset**: `aclk`, `aresetn` (active low, synchronous). One clock domain for all interfaces.
* **S_AXIS** (64 bit): `tdata = {Q1[63:48], I1[47:32], Q0[31:16], I0[15:0]}`, signed 16-bit, Q1.15.
  Antenna 0 is the reference element. `tready` is always 1.
* **M_AXIS** (64 bit): one beat per window, `tdata = {theta_deg_q16, phi_q28}`,
  `tuser[3:0] = {off_circle, overrun, ambiguous, no_signal}`, `tlast = 1`. The buffer is one deep.
* **irq**: level-high, `STATUS.result_valid & CTRL.irq_en`.

### Register map (AXI4-Lite, 64-byte window)

| Offset | Name | Access | Description (reset value) |
|---|---|---|---|
| 0x00 | CTRL | RW | [0] enable (1), [1] soft_reset (self-clearing), [2] irq_en (0), [3] use_cov (0) |
| 0x04 | STATUS | RW1C / RO | [0] result_valid, [3] overrun, [4] axis_drop (sticky, write 1 to clear); [1] no_signal, [2] ambiguous, [5] off_circle (last result); [31:16] result counter |
| 0x08 | LOG2_SNAP | RW | Window = 2^n snapshots, n ∈ [7, MAX_LOG2_SNAP] (10) |
| 0x0C | P_LOG2 | RW | p = 2^n for Cᵖ, n ∈ [0, 3] (2 → p = 4) |
| 0x10 | MU_Q30 | RW | μ of Eq. (17), unsigned Q30 (1024 ≈ 1e-6) |
| 0x14 | K_Q30 | RW | k = λ/(2πd), signed Q2.30 (341782638 = 1/π for d = λ/2) |
| 0x18 | PHI_Q28 | RO | Electrical phase φ = arg ψ = arg(x1/x0), rad, Q28 |
| 0x1C | PSI_MAG | RO | \|ψ\|, Q8.24 (≈ 1.0 when a source is present) |
| 0x20 | THETA_Q28 | RO | DOA θ, rad, Q28 |
| 0x24 | THETA_DEG | RO | DOA θ, degrees, Q16 (signed) |
| 0x28–0x34 | C00, C11, C01_RE, C01_IM | RO | Normalised cumulant matrix (debug, Q30 mantissas) |
| 0x38 | UC_TOL | RW | Unit-circle tolerance, Q8.24 (0x00400000 = 0.25) |
| 0x3C | ID | RO | 0x4D455332 ("MES2") |

Angle convention follows Eq. (2): `φ = −2πd·sin(θ)/λ`, so `θ = asin(−k·φ)`.

## Performance

* **Throughput**: one snapshot per clock. Windows run back to back; the minimum window is 128
  snapshots, enforced in hardware.
* **Latency** after the last snapshot of a window (from simulation): 139 cycles for p = 1, 165 for p = 4,
  178 for p = 8. That is about 1.65 µs at 100 MHz.
* **Resources** (Yosys `synth_xilinx -family xcup`, full AXI IP): 49 DSP48E2, 2 RAMB36, about 7.2 k FF,
  about 11.2 k LUT. Run `scripts/synth_check.tcl` for Vivado numbers and timing. It was not run here.
* **Timing (target 100 MHz)**: two registers after every wide multiplier (DSP MREG + PREG), a 2-stage
  normaliser, and a 4-stage arcsin interpolation behind a registered block-RAM read.
* **Accuracy vs. model**: worst |RTL − float model| = 0.0008° across all regression cases.

## Simulation

```bash
cd tb
./run_sim.sh            # all cases (iverilog >= 11, python3 + numpy)
./run_sim.sh no_source  # a single case
```

The cases are the same as for I-UESPRIT (p = 1/4/8, SNR 0–30 dB, −40 dBFS input, window lengths
128–1024 with gapped and back-to-back input, end-fire, covariance mode, AXI top). There is one extra
case, `no_source` (SNR −25 dB). In it the unit-circle test flags every window (`off_circle`, |ψ| ≈ 0.01),
and the checker verifies the `off_circle` flag against the model in every case.

## Packaging and use

```bash
vivado -mode batch -source scripts/package_ip.tcl                 # default part xczu4ev-sfvc784-1-i
vivado -mode batch -source scripts/synth_check.tcl -tclargs xczu4ev-sfvc784-1-i 10.0
```

```tcl
set_property ip_repo_paths <this dir>/ip_repo [current_project]
update_ip_catalog
create_bd_cell -type ip -vlnv user.org:dsp:m_esprit_2ant:1.0 doa_m_0
```

Bare-metal use is the same as for the I-UESPRIT IP. In addition, check `STATUS[5]` (off_circle), or
`PSI_MAG`, before trusting an angle:

```c
uint32_t st = Xil_In32(DOA_BASE + 0x04);
if ((st & 1) && !(st & (1u << 5))) {           /* result valid and on the unit circle */
    float theta_deg = (int32_t)Xil_In32(DOA_BASE + 0x24) / 65536.0f;
}
Xil_Out32(DOA_BASE + 0x04, 1);
```

## Notes for CRPA use

* One dominant source per two-element baseline. Use one IP per baseline for 2-D DOA.
* Gaussian-like noise jammers have a zero 4th-order cumulant. Use `CTRL.use_cov = 1` for them.
* Keep d ≤ λ/2. If |k·φ| > 1, θ is clipped to ±90° and `ambiguous` is set.
* Correct inter-channel phase and gain offsets upstream; they map directly into φ.
