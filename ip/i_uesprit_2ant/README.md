# I-UESPRIT 2-Antenna DOA Estimator IP

RTL implementation of the **modified ESPRIT / improved unitary ESPRIT (I-UESPRIT)** from

> J. Li, G. Yang, X. Ren, Z. Fu, S. Qiu, "Modified ESPRIT and Unitary-Transformation Form for
> Computationally Efficient DOA Estimation on FPGA", *IEEE Trans. Instrum. Meas.*, vol. 74, 2025,
> Art. 2003209.

specialised for a **two-element CRPA baseline** (M = 2), packaged as a Vivado IP with AXI4-Stream
data path and AXI4-Lite control.

## What the paper changes, and what it means for M = 2

| Paper step (Fig. 3) | Equation | RTL module | M = 2 realisation |
|---|---|---|---|
| **CMC**: 4th-order cumulant matrix, no source number needed | (7) | `uesprit_cmc_2x2` | Streaming moments: `E[x_m x_n*]`, `E[x_m x0]`, `E[\|x0\|² x_m x_n*]`, combined once per window |
| **RMA**: `C^p` | (38) | `uesprit_rma_2x2` | Repeated squaring of a 2×2 Hermitian, block-floating-point renormalised (p = 1, 2, 4, 8) |
| Forward–backward average | (26) | " | `C_fb = [[A, b],[b*, A]]`, `A = (c00+c11)/2` |
| Unitary transform → real | (25), (23) | " | `C_r = [[A+Re b, Im b],[Im b, A−Re b]]` |
| `K1`, `K2`, `C_r1`, `C_r2` | (30)–(34) | " | `K1 = √2[1 0]`, `K2 = √2[0 −1]` |
| `Ψ_r = (C_r1ᵀC_r1 + μI)⁻¹ C_r1ᵀ C_r2` | (36)–(37) | " | `C_r1` is 1×2, so `Ψ_r` has rank 1 and its only non-zero eigenvalue is its trace: **ψ = (r·s)/(\|r\|² + μ′)** |
| **PIE**: power-iteration EVD | Sec. IV | `uesprit_pie_dar` | Not needed: a single division (`uesprit_div_q24`) gives ψ exactly |
| **DAR**: `θ = asin(−λ/(πd)·atan ψ)` | (35) | `uesprit_pie_dar` | `φ = 2·atan2(N, D)` (CORDIC, no division), `u = −k·φ`, `θ = asin(u)` (block-RAM LUT with linear interpolation) |

`r = [cr00, cr01]`, `s = −[cr10, cr11]`. The √2 factors of `K1`, `K2` cancel, so
`μ′ = μ/2` (register `MU_Q30`). Because every quantity after the CMC is invariant to a common positive scale,
the RTL normalises with a power-of-two block exponent (`uesprit_bfp_norm4`). The result doesn't depend
on received power, and the datapath stays at 32–34 bits. `μ′` is therefore relative to a matrix whose largest entry is in [0.5, 1).

`model/i_uesprit_model.py selftest` checks numerically that the closed form equals the paper's generic
I-UESPRIT with a full EVD (max relative difference ≈ 1e-14).

## Interfaces

* **Clock/reset**: `aclk`, `aresetn` (active low, synchronous). One clock domain for all interfaces.
* **S_AXIS** (64 bit): `tdata = {Q1[63:48], I1[47:32], Q0[31:16], I0[15:0]}`, signed 16-bit, Q1.15.
  Antenna 0 is the cumulant reference element. `tready` is always 1 (one snapshot per clock max).
* **M_AXIS** (64 bit): one beat per window, `tdata = {theta_deg_q16, phi_q28}`, `tuser[3:0] = flags`,
  `tlast = 1`. The buffer is one deep; an unconsumed beat is overwritten (`STATUS.axis_drop`).
* **irq**: level-high, `STATUS.result_valid & CTRL.irq_en`.

### Register map (AXI4-Lite, 64-byte window)

| Offset | Name | Access | Description (reset value) |
|---|---|---|---|
| 0x00 | CTRL | RW | [0] enable (1), [1] soft_reset (self-clearing), [2] irq_en (0), [3] use_cov (0) |
| 0x04 | STATUS | RW1C / RO | [0] result_valid, [3] overrun, [4] axis_drop (sticky, write 1 to clear); [1] no_signal, [2] ambiguous (last result); [31:16] result counter |
| 0x08 | LOG2_SNAP | RW | Window = 2^n snapshots, n ∈ [7, MAX_LOG2_SNAP] (10 → 1024, as in the paper) |
| 0x0C | P_LOG2 | RW | p = 2^n for C^p, n ∈ [0, 3] (2 → p = 4, as in the paper) |
| 0x10 | MU_Q30 | RW | μ′ of Eq. (37), unsigned Q30 (1024 ≈ 1e-6) |
| 0x14 | K_Q30 | RW | k = λ/(2πd), signed Q2.30 (341782638 = 1/π for d = λ/2). A negative value flips the angle sign convention |
| 0x18 | PHI_Q28 | RO | Electrical phase φ = arg(x1/x0), rad, Q28 |
| 0x1C | PSI_Q24 | RO | ψ, the eigenvalue of Ψ_r (= tan(φ/2)), Q8.24, saturated |
| 0x20 | THETA_Q28 | RO | DOA θ, rad, Q28 |
| 0x24 | THETA_DEG | RO | DOA θ, degrees, Q16 (signed) |
| 0x28–0x34 | C00, C11, C01_RE, C01_IM | RO | Normalised cumulant matrix (debug, Q30 mantissas) |
| 0x3C | ID | RO | 0x45535032 ("ESP2") |

Angle convention follows Eq. (2): `φ = −2πd·sin(θ)/λ`, so `θ = asin(−k·φ)`. A source on the antenna-1 side
(antenna 1 receives the wavefront first, i.e. x1 leads x0) gives θ < 0 with the default positive `K_Q30`.

## Numerical formats

| Signal | Format |
|---|---|
| ADC input | Q1.15 |
| Second-order moments | Q2.30 (33-bit samples, 33+log2 T accumulators) |
| Fourth-order moments, cumulant | Q4.60 (66-bit samples, 66+log2 T accumulators, 72-bit cumulant) |
| Everything after the CMC | 32-bit block-floating mantissas (largest entry ∈ [0.5, 1)), 34×34 products |
| φ, θ | Q28 rad; θ also Q16 degrees |

The accumulators are full precision (no rounding before the cumulant), so weak signals keep their
accuracy. In the regression, a −40 dBFS tone gives the same answer as the floating-point model to within 0.0004°.

## Performance

* **Throughput**: one snapshot per clock. Windows run back to back, and the next window accumulates while the
  previous one goes through CMC-combine → RMA → PIE/DAR. The minimum window is 128 snapshots: the
  PIE/DAR stage is busy for about 64 cycles, and the hardware enforces this minimum.
* **Latency** after the last snapshot of a window (from simulation): 100 cycles for p = 1, 118 for p = 4, 127 for p = 8.
  That is about 1.2 µs at 100 MHz; the paper reports 1008 cycles for M = 4.
* **Resources**: Yosys `synth_xilinx -family xcup` estimate for the full AXI IP: 45 DSP48E2, 2 RAMB36,
  about 5.3 k FF, and about 12 k LUT before Vivado optimisation. Vivado usually reports fewer LUTs. Run
  `scripts/synth_check.tcl` for real numbers and timing on your part. The design was not run through Vivado here.
* **Accuracy vs. model**: worst |RTL − float model| = 0.0004° across all regression cases. The arcsin LUT error
  is below 0.0005° for |sin θ| < 0.99 and below 0.12° at end-fire.

## Simulation

```bash
cd tb
./run_sim.sh            # all cases (needs iverilog >= 11, python3 + numpy)
./run_sim.sh cum_p4_snr10
```

Each case generates 2-antenna snapshots (tone / QPSK / chirp, AWGN, 16-bit quantised) with
`model/i_uesprit_model.py gen`. The case then runs the RTL and compares every window's θ with the model
(`model/i_uesprit_model.py check`). The cases cover p = 1, 4, 8, SNR 0–30 dB, low amplitude, window
lengths 128–1024 with gapped and back-to-back input, end-fire angles, covariance mode, and the AXI top
(register programming, interrupt, W1C, M_AXIS).

## Packaging and using the IP in Vivado

```bash
vivado -mode batch -source scripts/package_ip.tcl                 # default part xczu4ev-sfvc784-1-i
vivado -mode batch -source scripts/package_ip.tcl -tclargs <part> <ip_repo_dir>
```

Then, in your project:

```tcl
set_property ip_repo_paths <this dir>/ip_repo [current_project]
update_ip_catalog
create_bd_cell -type ip -vlnv user.org:dsp:i_uesprit_2ant:1.0 doa_0
```

Typical connections: put the ADC/DDC output for both antennas (packed `{Q1,I1,Q0,I0}`) on `S_AXIS`. Connect
`S_AXI` to the PS through an AXI interconnect / SmartConnect, and `irq` to `pl_ps_irq`. Send `M_AXIS` to
your beam-steering / nulling logic, or to an AXI DMA / AXI-Stream FIFO.

Bare-metal use:

```c
#define DOA_BASE 0xA0000000u
Xil_Out32(DOA_BASE + 0x08, 10);            // 1024 snapshots
Xil_Out32(DOA_BASE + 0x0C, 2);             // p = 4
Xil_Out32(DOA_BASE + 0x14, 341782638);     // d = lambda/2
Xil_Out32(DOA_BASE + 0x00, 0x5);           // enable + irq
/* in ISR or poll: */
while (!(Xil_In32(DOA_BASE + 0x04) & 1));
float theta_deg = (int32_t)Xil_In32(DOA_BASE + 0x24) / 65536.0f;
Xil_Out32(DOA_BASE + 0x04, 1);             // clear result_valid
```

## Notes for CRPA use

* **One DOA per baseline.** With two elements, the ESPRIT subarrays have one element each, so the
  estimator resolves exactly one dominant source (the strongest non-Gaussian emitter) per baseline. For
  azimuth and elevation, instantiate one IP per orthogonal baseline of the CRPA (e.g. elements 0–1 and 0–2).
* **Gaussian-like noise jammers.** The 4th-order cumulant of a Gaussian process is zero. That is what
  suppresses receiver noise, and it also suppresses wideband noise jammers. CW, swept/chirp, pulsed, and
  digitally modulated (BPSK/QPSK) jammers have non-zero cumulants and work as intended. For noise-like
  jammers, set `CTRL.use_cov = 1`: the same unitary-ESPRIT chain then runs on the covariance matrix, and C^p
  (p ≥ 4) reduces the noise-floor bias.
* **Spacing.** Keep d ≤ λ/2 for unambiguous angles. If |k·φ| > 1, θ is clipped to ±90° and
  `STATUS.ambiguous` is set.
* **Calibration.** Inter-channel phase or gain offsets map directly into φ. Correct them upstream (complex
  gain per channel), or subtract a calibrated φ offset before using the angle.

## Relation to the earlier ESPRIT chain (`Espirit_Test`)

The earlier chain (`complex_covariance_2x2 → eig2x2_hermitian → dominant_eigenvector_2x2 →
esprit_1src_2ant_angle`) is conventional ESPRIT: complex covariance, an explicit EVD with square root and
division, and a source count fixed at one. This IP replaces it with the paper's method:

* cumulant-based subspace, so no source-number assumption and Gaussian noise is suppressed
* C^p sharpening
* real-valued unitary arithmetic
* no square root and no EVD (the closed-form eigenvalue for M = 2)
* the DOA angle is computed in hardware

Phase sign: the old `esprit_1src_2ant_angle` output `angle(Es1·conj(Es2)) = −φ`. This IP outputs
`φ = arg(x1/x0)`, as in the paper's Eq. (2).
